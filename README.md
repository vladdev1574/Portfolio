# Independent Developer Portfolio

Local, static portfolio built with HTML, CSS, and vanilla JavaScript. No build step or publishing integration is required.

## Current version

- `main.html` — paper/editorial homepage
- `case-study-*.html` — six individual case studies
- `style.css` — global layout, paper textures, motion, and responsive rules
- `case-study.css` — case-study layout and scrollable website reels
- `script.js` — project data, interactions, and injected website reels
- `assets/projects/` — optimized screenshots from the live projects
- `assets/projects/fullpage/` — desktop and mobile full-page captures used by the case-study reels
- `tools/capture-full-pages.cjs` — repeatable full-page capture and optimization utility
- `tools/verify-reels.cjs` — local interaction check for every case-study reel

Open `main.html` directly, or serve this folder locally for the most consistent font and navigation behavior.

## Preserved previous version

The complete pre-redesign version is stored in `versions/portfolio-v1/`. Its `main.html` can be opened independently.

## Publishing

This workspace is intentionally local-only. Publish manually only when the portfolio is approved.
